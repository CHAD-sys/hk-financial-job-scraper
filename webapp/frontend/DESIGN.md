# FinEx Careers — Design System

Generated by **ui-ux-pro-max** skill v2.6.2.
Aesthetic target: Bloomberg / Financial Times gravitas × Stripe polish.
Style system: **Minimalism & Swiss** — high contrast, generous whitespace, strict type hierarchy.

## Typography

**Stack**: Playfair Display (display serif) + Inter (UI sans) + JetBrains Mono (data/labels)

> **Source**: ui-ux-pro-max `--domain typography "authoritative serif premium institutional fintech"` →
> Classic Elegant (Playfair + Inter) enhanced with JetBrains Mono for financial data density.

### Fonts
| Role | Family | Weights | Usage |
|------|--------|---------|-------|
| Display | Playfair Display | 400, 600, 700, 800 | Hero headlines, wordmark, section heads |
| Sans | Inter | 300, 400, 500, 600, 700 | Body copy, UI labels, nav, captions |
| Mono | JetBrains Mono | 400, 500 | Stat numbers, data labels, code snippets |

### Type Scale
| Level | Size | Weight | Font | Usage |
|-------|------|--------|------|-------|
| Hero | `clamp(2.75rem, 5.5vw, 4.25rem)` | 700 | Display | Landing headline |
| H1 | `clamp(2rem, 4vw, 3rem)` | 700 | Display | Page titles |
| H2 | `clamp(1.5rem, 2.5vw, 2rem)` | 600 | Display | Section headings |
| H3 | `1.25rem` | 600 | Sans | Sub-section heads, card titles |
| Body | `1rem` | 400 | Sans | Standard copy (line-height 1.65) |
| Small | `0.875rem` | 400/500 | Sans | Secondary text, nav links |
| Label | `0.75rem` | 500 | Sans | Uppercase eyebrows (tracking-widest) |
| Stat | `1.875rem` | 700 | Mono | Dashboard numbers (tabular-nums) |

### Rules
- Headings: `letter-spacing: -0.02em` — tight for institutional gravitas
- Labels/eyebrows: `letter-spacing: 0.1em; text-transform: uppercase` — Swiss style
- Stat numbers: `font-variant-numeric: tabular-nums` — prevents layout shift in data views
- Body line-height: `1.65` — generous for financial text density
- Max line length: `65ch` on desktop, `50ch` on mobile

## Spacing System

Base unit: **4px** (following Material Design 4dp grid).

```
4   → 0.25rem  (tight padding, icon gaps)
8   → 0.5rem   (inline gaps, badge padding)
12  → 0.75rem  (compact component padding)
16  → 1rem     (standard component padding)
24  → 1.5rem   (section inner padding)
32  → 2rem     (card padding, section gaps)
48  → 3rem     (section vertical rhythm)
64  → 4rem     (major section breaks)
80  → 5rem     (hero vertical padding)
96  → 6rem     (large section breaks)
128 → 8rem     (page-level spacing)
```

## Elevation / Shadow Scale

Defined in `--shadow-*` tokens. Each level adds depth without heavy drop shadows
(Swiss minimalism: shadows should be structural, not decorative).

| Token | CSS Value | Usage |
|-------|-----------|-------|
| `--shadow-card` | `0 1px 3px rgb(0 0 0 / 0.06), 0 1px 2px -1px rgb(0 0 0 / 0.04)` | Default card resting state |
| `--shadow-raised` | `0 4px 16px -2px rgb(0 0 0 / 0.08), 0 2px 6px -2px rgb(0 0 0 / 0.04)` | Card hover, active dropdowns |
| `--shadow-float` | `0 12px 40px -8px rgb(0 0 0 / 0.12), 0 4px 12px -4px rgb(0 0 0 / 0.06)` | Modals, command palette, tooltips |

## Motion

> **Source**: ui-ux-pro-max Quick Reference §7 (Animation) — duration 150–300ms,
> ease-out for enter, ease-in for exit, transform/opacity only.

| Token | Value | Usage |
|-------|-------|-------|
| Fast | `150ms` | Hover state changes, button press |
| Base | `200ms` | Most UI transitions |
| Slow | `300ms` | Page-level transitions, modals |
| `--ease-out-expo` | `cubic-bezier(0.16, 1, 0.3, 1)` | Enter animations (feels snappy) |
| Ease-in-out | `cubic-bezier(0.4, 0, 0.2, 1)` | State toggles |

**Rules**:
- Only animate `transform` and `opacity` — never `width`, `height`, `top`, `left`
- All interactive elements transition in `200ms ease-out`
- Hover: lift shadow from `card` → `raised`; color shift on text
- Respect `prefers-reduced-motion` — durations collapse to `0.01ms`

## Component Patterns

### Navigation Bar
`sticky top-0`. Two tiers on desktop, one row on mobile.

| | Mobile (`< lg`) | Desktop (`lg+`) |
|---|---|---|
| Structure | single row | utility strip over nav row |
| Utility strip | — | 44px, `--color-nav`, wordmark + Post a role / Saved / account |
| Nav row | — | 44px, `--color-masthead`, all six links |
| Single row | 64px, `--color-nav`, wordmark + Saved + hamburger | — |
| Total (`--nav-height`) | 65px | 90px |

- The two tiers are separated by a **tonal step**, not just the hairline
  divider. Two dark surfaces at the same value read as one muddy block.
- **Dark surfaces step monotonically, never oscillate.** Down the page:
  `--color-nav` (deep chrome) → `--color-masthead` → light content. A dark page
  hero directly under the nav therefore uses `--color-masthead`, *not*
  `--color-nav` — painting it `--color-nav` again strands the lighter nav row
  between two darks and it reads as a stray stripe. Applies to every hero
  sitting under the nav: `/jobs`, `/about`, `/saved`, `/learning`.
- `--nav-height` includes the 1px borders — it is the header's outer bottom
  edge, which is what the job detail panel and scroll clearance anchor to.
  **Change a tier's height and you must change this token**, plus the
  `lg:scroll-mt-26` on hash-target sections.
- Wordmark: Playfair Display, gold italic for "Careers"
- Links: `rgba(248,250,252,0.6)` → `#F8FAFC` when active
- Active page: `--color-gold-star` 2px underline. Not `--color-gold` — the
  darker gold is illegible on navy at hairline weight.
- External links (Market Research) carry an `ArrowUpRight` and open in a new tab.
- CTA: gold pill button

### Stat Cards
- Background: `--color-surface` with `1px --color-border` border
- Value: JetBrains Mono, 30px bold, ink
- Label: Inter 500, uppercase tracking-widest, gold
- Sub: Inter 400 12px, ink-faint
- Hover: shadow elevates from `card` → `raised`

### Primary CTA Button
- Background: `--color-ink` (navy) → `--color-blue` on hover
- Text: `--color-ink-inverse`
- Padding: `0.75rem 1.5rem`
- Radius: `0.25rem` (4px — Swiss, not rounded-full)
- Transition: `200ms ease-out` background-color

### Closed Roles
A Role that has closed appears only in Saved Roles and on a direct detail URL —
the board never returns one (ADR 0010). The card must therefore be identifiable
*across a grid*, not on inspection, which a badge cannot do.

- **Band, not badge.** `--color-closed` fills a full-width band across the head
  of the card, in the slot the 2px sector accent occupies on a live card. One
  word, `CLOSED`, uppercase 13px/700 at `0.16em` tracking, `--color-ink-inverse`.
- **No chroma.** The card gives up its sector palette, its gold/purple tier
  chips and its seniority colour, all substituted for neutrals in one place
  (`CLOSED_NEUTRAL` in `JobCard.tsx`). Surrounding live cards keep theirs, and
  that absence is the signal that carries at distance.
- **No liveness claims.** "Urgently hiring", "New", applicant counts, recruiter
  attribution and the "Verified" chip are all assertions about a vacancy someone
  can still apply to. They are removed, not greyed.
- **Four redundant channels**: value (dark band on a recessed surface), position
  (head of the card), pattern (45° hatching on the band), and the word itself.
  Nothing depends on hue — it survives greyscale.
- Neutralised chip text is `--color-ink-muted` (~5.6:1 on `--color-surface-2`),
  never `--color-ink-faint` (~2.4:1). Removing colour must not remove contrast.
- **Not the disabled treatment.** No opacity wash, no `not-allowed` cursor: the
  card stays clickable, because revisiting what you applied to after it closed
  is the reason the Role is still saved at all. Archived, not switched off.

### Section Dividers
- Use `1px solid --color-border` — never bold rules
- Gold top rule on hero (`0.125rem` height) — FT masthead reference

## Accessibility Compliance

- All text colors verified at ≥4.5:1 contrast on respective backgrounds (WCAG AA)
- Gold `#9A6F00` on white: 4.71:1 ✓
- Navy `#0B1628` on white: 17.4:1 ✓
- Muted `#475569` on white: 5.74:1 ✓
- Focus rings: `2px solid --color-ring (#1E3A8A)`, offset 2px
- All interactive elements ≥44px touch target height
- `prefers-reduced-motion` collapses all transitions
- Semantic HTML: `<header>`, `<main>`, `<nav aria-label>`, `<footer role="contentinfo">`
- Skip-to-content: `id="main-content"` on `<main>`

---

## Anti-Patterns (from ui-ux-pro-max)

- No emoji as structural icons — use Lucide React exclusively
- No raw hex values in components — reference CSS tokens only
- No `100vh` — use `100dvh` / `min-h-dvh`
- No horizontal scroll on any viewport
- No `width`/`height` animations — `transform` + `opacity` only
- No inline-only validation — validate on blur
- No hidden filters or outdated form patterns
