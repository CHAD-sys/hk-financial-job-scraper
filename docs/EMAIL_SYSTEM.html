FinEx Careers email system

Current production responsibilities, updated 11 August 2026.

Scheduled Daily Run results

.github/workflows/daily.yml sends the completed scheduled-run result to both administrators. Success uses the resulting jobs database; failure includes the GitHub run URL.

  • SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS
  • NOTIFY_EMAILS contains the administrator recipients.

Recruiter Role submissions

POST /api/post-role writes every accepted submission to submitted_roles.jsonl before attempting a notification through webapp/backend/mailer.py. The fixed destination is configured by SUBMISSION_EMAIL.

The honeypot, rate limit, input caps, URL validation and header sanitising protect the public submission route. SMTP failure never removes the queued Role.

Seeker account messages

Verification and password-reset messages use the dedicated Seeker sender. The target address comes from the authenticated account flow and is protected by per-address limits. See ADR 0009.

Health checks

GET /health reports whether submission email is configured, the fixed Role-submission recipient and the durable submission directory.
